# 🎬 Movie Collection System

A desktop **Movie Collection Management System** developed using **Java and JavaFX**.
The application provides a graphical user interface (GUI) for managing a personal movie collection, allowing users to add, edit, delete, search, and view movies, as well as manage their movie lists and statistics.

## 📌 Overview

The **Movie Collection System** is a JavaFX-based desktop application designed to provide an easy and user-friendly way to organize and manage a collection of movies.

Through the graphical interface, users can manage movie information, create and view personal lists, and analyze their collection through statistics.

## ✨ Features

* 🎬 **Add Movies** — Add new movies to the collection.
* ✏️ **Edit Movies** — Update existing movie information.
* 🗑️ **Delete Movies** — Remove movies from the collection.
* 👀 **View Movies** — Browse and display available movies.
* 📋 **My List** — Manage a personal list of selected movies.
* 📊 **Statistics** — Display statistics and information about the movie collection.
* 🖥️ **Graphical User Interface** — Interactive GUI built with JavaFX.
* 🎨 **CSS Styling** — Custom styling using JavaFX CSS.

## 🏗️ Project Structure

| File                 | Description                                                    |
| -------------------- | -------------------------------------------------------------- |
| `Main.java`          | Main entry point of the application.                           |
| `MainDashboard.java` | Main dashboard/interface of the application.                   |
| `Movie.java`         | Movie model containing movie-related information and data.     |
| `InsertMovies.java`  | Handles inserting and adding movies to the collection.         |
| `ViewMovies.java`    | Displays the movies available in the collection.               |
| `MyList.java`        | Handles the user's personal movie list.                        |
| `Listable.java`      | Provides functionality related to list management.             |
| `Statistics.java`    | Calculates and displays statistics about the movie collection. |
| `application.css`    | JavaFX CSS file used to style the graphical interface.         |

## 🖥️ Application Interface

The application is built as a **JavaFX GUI**, providing multiple screens for interacting with the movie collection.

The main dashboard provides access to the core functionality of the system, including movie management, personal lists, and statistics.

## 🔄 Main Functionality

### 1. Add Movie

Users can enter movie information through the GUI and add a new movie to the collection.

### 2. Edit Movie

Existing movie information can be modified when changes are needed.

### 3. Delete Movie

Movies can be removed from the collection through the graphical interface.

### 4. View Movies

Users can browse the available movies and view their information.

### 5. My List

Users can create and manage a personal list of movies they are interested in or want to keep track of.

### 6. Statistics

The system provides statistics related to the movie collection, helping users analyze their movies and get an overview of their collection.
